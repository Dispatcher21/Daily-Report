# ======================================================================
#  TUTORIAL DIALOGUE
#  Everything the inspector says during the tutorial lives in this file.
#  Edit it, save it, and the site picks up the changes on the next page
#  load. No code changes and no app update needed.
# ======================================================================
#
# HOW IT WORKS
#  - Lines starting with # (like this one) are notes for you. The app
#    ignores them.
#  - Each page starts with a header like:
#        === PROJECT PAGE (project.html) ===
#    The file name in (parentheses) is what ties the lines to the page.
#    The words before it are just a label for you.
#  - Each line the inspector says starts with a number in [brackets],
#    then an Emotion line, a Points at line, and the text. The numbers
#    are only labels: lines play in the order they appear in this file,
#    so you can move one just by cutting and pasting it.
#  - The text can run over several lines; they're joined into one
#    paragraph. Leave a blank line inside the text to start a new
#    paragraph. Don't start a text line with #.
#  - Besides the pages, five special sections (WELCOME, the two role
#    welcomes, EXPLORE ON YOUR OWN, and NO TIPS YET) are explained where
#    they appear below.
#  - Keep each line to 2-3 sentences. On a phone the box fits about 4
#    short lines before it crowds the screen.
#
# FOR (who hears the line)
#  The welcome asks whether they're an inspector or a manager. A line
#  with "For: inspector" only plays for inspectors, and "For: manager"
#  only for managers. Leave the For line out (or write "For: everyone")
#  and everyone hears it. To give the two roles different wording for
#  the same spot, write the line twice, once for each.
#
# EMOTIONS (which character image shows)
#    neutral, happy, thinking, surprised, pointing
#  An unknown emotion shows neutral.
#
# POINTS AT (what the hand taps while the line shows)
#  Use one of the names listed for that page below, or "nothing".
#  Capital letters, "the", and anything in (parentheses) are ignored, so
#  "the menu button (top left)" works the same as "menu button".
#  If a name isn't on the list, or the thing isn't on screen right then,
#  the line still shows, just without the hand.
#
#  Any page:    menu button, sync button, tutorial bar, tips button,
#               breadcrumb, activity banner
#  Home:        portfolio panel, activity calendar, project card,
#               add project card
#  Project Settings: section list, project info, pay items,
#               contractors, preview, save button
#  Project:     new report tile, view reports tile, quantities tile,
#               pay apps tile, dashboard overview, pay items panel,
#               weather panel, trend chart, project settings button
#  Reports:     filters, search box, view toggle, report list,
#               first report, checkbox, select all, comment badge,
#               new report button, deleted reports, sent back report
#  Viewer:      report page, side reports, details bar, review bar,
#               pinned comment, edit button
#  Editor:      no work day button, weather day button, report info,
#               date field, inspectors, sections, contractors section,
#               pay items section, weather section, fetch weather button,
#               photos section, live preview, preview tabs, save button,
#               generate button, duplicate button, add inspector button,
#               add pay item button, overview section, work summary
#               section, tests section, controlling item section, site
#               conditions section, sign-off section
#  Quantities:  section tabs, pay apps tab, contract bar, range options,
#               item list, first item, check chip, view toggle,
#               excel button, log quantities button
#  Log Quantities: date field, day arrows, item list,
#               first quantity box, running total,
#               add item not in catalog, save button
#  Pay Apps:    pay app list, first pay app, new pay app button, status,
#               contract bar, breakdown, differences filter, period link,
#               excel file, review section
#  Download:    logo warning, pdf preview, download button
#  Photos:      photos, view report button
#  Manager:     reports to review, first report, pay apps to review,
#               managed projects, project checkboxes
#  Settings:    you tab, company tab, profile, appearance, theme buttons,
#               accent colors, app section, tutorial section, account section,
#               sync to folder
#
#  Need to point at something that isn't listed? Ask and it can be added.
