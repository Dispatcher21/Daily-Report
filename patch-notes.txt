DAILY WORK REPORTS -- PATCH NOTES
==================================

Newest first. Dates are when the work shipped.

0.023 -- 2026-09-21
  - The Audit Log now shows per-inspector detail again -- who was added or
    removed on a report and whose Hours changed, not just the combined
    Representative name. Who actually made the edit was always the
    logged-in device, unaffected either way.

0.022 -- 2026-09-21
  - View Reports now shows a banner at the top when the linked folder has
    reports waiting to sync, with a Sync Now button right there -- no more
    needing to notice a small cloud icon or go find the Sync button on the
    Project page.

0.021 -- 2026-09-21
  - View Reports now shows multiple inspectors as separate, differently
    colored name badges instead of one combined name.
  - Fixed the Edit button drifting to a different spot on some report
    cards/rows depending on how much other content was above it -- it now
    always sits flush at the bottom.

0.020 -- 2026-09-21
  - Each inspector now has their own plain Hours box, next to their name --
    type a number directly instead of needing the time-segment calculator.
    Using the calculator for an inspector still fills their Hours in
    automatically and takes over from anything typed by hand.

0.019 -- 2026-09-21
  - The Inspectors section in Time Worked is now collapsed by default --
    only the plain Hours box shows until you open it. It still opens
    automatically for a report that already has real inspector time
    logged, so nothing already filled in stays hidden.

0.018 -- 2026-09-21
  - Fixed the Hours and Representative lines on the printed report: Hours
    now shows each inspector's initials and hours (e.g. "JS (1hr),
    AF (2hr)") and the Representative line shows everyone's full name
    (e.g. "John Sonnier, Alex Flores") -- these had been swapped.
  - Folder sync now picks up where it left off if interrupted, instead of
    starting the whole project over -- each report is marked done as soon
    as it's written, not only after the entire sync finishes. It also
    warns before leaving the page while a folder sync is actively running.

0.017 -- 2026-09-21
  - Added support for multiple inspectors on one report, each with their
    own logged time -- add them under Time Worked in the report editor.
    Hours now totals everyone's segments together, and the printed report
    lists each inspector's initials and hours on the sign-off line (e.g.
    "JS (10hr), AF (2hr)") when there's more than one.
  - The Time Worked box now always shows the Hours field up front, with
    only the detailed time-segment calculator (per inspector) tucked
    behind a small toggle -- it was easy to miss before.
  - View Reports now shows the Representative/Inspector name on each
    report row instead of whoever's device happened to create it, when
    the two differ.

0.016 -- 2026-09-21
  - Fixed Reports' multi-select checkboxes being unavailable to anyone
    without edit permission on a report -- they're needed for Generate
    Selected and Build Quantity Sheet too, which don't require editing at
    all, so selecting reports is available to everyone again. Mass Edit
    and Delete stay limited to whoever's actually allowed to make those
    changes.

0.015 -- 2026-09-16
  - Fixed the report editor's live preview flashing on every character
    typed -- photos and the logo were reloading from scratch on every
    update instead of staying put.
  - Settings no longer flashes "You" and then jumps to "Company" when an
    admin opens it. It stays on "You" until Company is actually clicked.

0.014 -- 2026-09-16
  - Removed a couple of old, unused code paths left over from features that
    were already retired (an old export format nothing pointed to anymore,
    and the "share a report" half of a feature that only ever supported
    receiving, not sending). No visible change -- just less to maintain.

0.013 -- 2026-09-16
  - Company/admin/custom-setup passwords now need at least 8 characters.
  - The company password, join, and admin unlock screens now slow down
    automatically after a few wrong tries in a row, instead of allowing
    unlimited guesses back-to-back.
  - The Audit Log now flags an entry if its content doesn't match what was
    originally recorded, as a heads-up that it may have been altered
    outside the app.

0.012 -- 2026-09-16
  - Updated the Excel library (SheetJS) to close a known security issue in
    the older version. Excel import/export files you use are unaffected --
    just handled by a patched library now.

0.011 -- 2026-09-16
  - Added a Content-Security-Policy to every page, limiting what scripts,
    connections, and embedded content the app will run or load.
  - Strengthened the admin password check to a much slower, salted method
    (existing companies upgrade automatically the next time an admin logs
    in -- no action needed).
  - Updated the PDF library (jsPDF) to the latest 2.x release.

0.010 -- 2026-09-16
  - Folder sync no longer deletes anything. A report deleted or renamed in
    the app now renames its old files in the synced folder with a
    DELETED_ prefix and leaves them in place, instead of removing them.

0.009 -- 2026-09-16
  - Added folder sync/backup: pick a folder on this device and every report
    syncs to it automatically as a real PDF, plus a full Quantity Sheet and
    the raw data behind it -- no manual export needed.
  - New reports sync to that folder in the background the moment you save,
    with a small status icon on anything not caught up yet.
  - The header refresh button now also catches up the current project's
    folder sync.
  - Reworked both dashboards' overview stats into one consistent, cleaner
    layout.
  - Compacted the No Work Day / Weather Day buttons into a single row.
  - Activity, Representative, and PE Name each now fill their old duplicate
    box automatically -- one entry instead of two. Short Work Summary
    retired.

0.008 -- 2026-09-15
  - Split report viewing into its own page, separate from editing.
  - Added manual drag-to-reorder and folder favoriting on the home screen.
  - Overhauled the Quantity Sheet into a tabbed, quantities-first page;
    moved Pay Apps to its own page.
  - Restyled Quantity Sheet exports with real spreadsheet formatting, new
    export options, and the company logo on the cover page.
  - Added "Duplicate This Report."
  - Added global search in the header.
  - Added photo markup -- pen and arrow annotations on report photos.

0.007 -- 2026-09-14
  - Existing reports now open in a locked, view-only mode by default --
    tap a field to unlock and edit it.
  - View mode shows just the clean printed preview.

0.006 -- 2026-09-11
  - Added drag-to-organize project folders on the home screen, with
    iOS-style open/close animations.
  - Folder cards now preview the projects inside them; added custom
    project icons and folder backgrounds.
  - Consolidated every refresh/sync button into one, in the header.
  - Overhauled Settings into a unified You/Company tabbed page.
  - Added a Force Update option, with automatic prompts when an update's
    ready to install.
  - Assorted fixes: folder drag-and-drop with a mouse, touch drag fighting
    the page's own scroll, folder tiles hiding behind a background image,
    a folder modal capped too narrow, sloppy Company Management layout.

0.005 -- 2026-09-10
  - Confirmed a report's sync actually lands when Save is pressed, instead
    of trusting it silently.
  - Company syncs are noticeably faster (delta sync instead of re-reading
    everything every time).
  - Added a full Company Theme Builder -- accent color, home screen
    background, and decorative artwork, with a live preview and animated
    GIF support.
  - Added a Company Management link to Settings, admin-only.
  - Theme changes now log to the Audit Log in plain language.
  - Fixed a save-blocking error message that could get squeezed out of view
    on desktop.

0.004 -- 2026-09-09
  - Fixed HEIC photos (the default iPhone camera format) showing up as
    broken images.

0.003 -- 2026-09-08
  - Added a Daily Work Report Excel importer to Project Setup, including

  - The report upload zone on the Project page now also accepts Excel
    imports.
  - Report imports show live progress instead of a silent wait.
  - A Pay App Total can now be typed in as a raw dollar amount.
  - Fixed bulk report imports silently losing data on the way to the

  - Fixed a company sync slowdown that could take several minutes.
  - Report editor now returns to the Reports list after Save.
  - Fixed Progress Over Time and Lump Sum % Complete undercounting.
